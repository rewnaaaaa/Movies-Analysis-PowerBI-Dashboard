# 🎬 Movies Analysis Power BI Dashboard

Welcome to my first Power BI project! This dashboard provides an interactive and clean overview of a movies dataset.

## 📊 Dashboard Features & Highlights:
- **KPI Cards:** Displaying Total Movies, Average IMDb Rating, and total votes.
- **Interactive Slicer:** Filter data easily by `Decade_DAX`.
- **Top 10 Analysis:** Bar chart visualizing top-rated/ranked movies.
- **Trend Analysis:** Line chart showing movie trends by year.
